# Тестирование Sauce Demo

Учебный проект по ручному тестированию веб-приложения [saucedemo.com](https://www.saucedemo.com): это демо-магазин, который специально сделан для практики тестировщиков. В нём несколько учётных записей с разным поведением, корзина и оформление заказа.

Автор: Кружков Алексей, 2026.

## Что проверялось

- авторизация: верные и неверные данные, пустые поля;
- корзина: добавление и удаление товаров из каталога и из карточки товара;
- оформление заказа: форма данных покупателя, расчёт налога и итога, переходы между шагами, кнопка «Назад», обновление страницы, прямые ссылки на шаги.

## Где смотреть

Вся работа ведётся в [Issues](../../issues):

- [тест-кейсы](../../issues?q=is%3Aissue+label%3Atest-case+sort%3Acreated-asc): в названии код вида [TC-CHK-008], где AUTH означает авторизацию, CART корзину, CHK оформление заказа;
- [баг-репорты](../../issues?q=is%3Aissue+label%3Abug): шаги воспроизведения, ожидаемый и фактический результат, окружение, серьёзность и приоритет;
- [предложения по улучшению](../../issues?q=is%3Aissue+label%3Aenhancement).

Тест-кейсы и баги заводятся через формы, их шаблоны лежат в [.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE).

## Техники тест-дизайна

Кейсы получены из разбора функциональности техниками тест-дизайна:

- классы эквивалентности и граничные значения (форма входа);
- предугадывание ошибок (оформление заказа);
- таблица решений (обязательные поля формы покупателя);
- переходы состояний (корзина и шаги заказа, включая недопустимые переходы);
- сценарий использования (сквозной путь покупки);
- попарное тестирование (выбор конфигураций для прогона: пользователь, браузер, устройство).

## Окружение

Windows 11, Microsoft Edge, ПК; учётные записи standard_user, problem_user и visual_user.
